# NEXUS Supply Chain Risk Intervention System - Technical Specification

## 1. Overview

Automated pipeline for supply chain disruption detection, risk assessment, mitigation option generation, and decision support with human approval workflow.

## 2. Agent Pipeline

### 2.1 Signal Agent (LLM-based Extraction)

**Input**: Risk_Sinyalleri sheet, Raw "Ham Metin" column

**Processing**:
1. Read signal metadata from Excel
2. Extract structured information from raw text using LLM
3. Match shipments to signals using tracking number rules

**LLM Prompt**:
```
Extract the following information from the signal text:
1. Event type (port closure, strike, weather, quality issue, etc.)
2. Country/region affected
3. Party involved (supplier/carrier code)
4. Affected shipment number (try to match to Sevkiyatlar sheet)
5. Material number
6. Estimated delay in days
7. Alternative option hints in the text

Return JSON format only.
```

**Fallback Mode** (if no LLM):
- Parse known patterns from signal text
- Use pre-registered extractions for common signal types

**Output Model**:
```python
class SignalExtraction(BaseModel):
    signal_id: str
    event_type: str
    country_region: str
    party_code: Optional[str] = None
    shipment_id: Optional[str] = None
    material_no: Optional[str] = None
    estimated_delay_days: Optional[int] = None
    alternative_hints: List[str]
    confidence: float
    extraction_method: str  # "llm" or "pattern_match"
```

### 2.2 Risk & Impact Agent (Deterministic)

**Input**: 
- Signal extraction from Agent 1
- Sevkiyatlar, Stok_Durumu, Uretim_Hatlari, Malzemeler, Tedarikciler, Tasiyicilar, Musteri_Siparisleri, Parametreler, Esik_Tablolari sheets

**Processing**:
1. Calculate probability (weighted sum of 4 scores)
2. Estimate impact (financial + operational)
3. Compute risk score = probability × impact
4. Calculate stock coverage and depletion date
5. Estimate production line downtime
6. Calculate total cost of inaction

**Formulas**:
```
Olasılık = 0.4×Sinyal + 0.3×Performans + 0.2×DışKoşul + 0.1×Finansal
Risk_Puanı = Olasılık × Etki

Stok_Günü = Mevcut_Stok / Günlük_Tüketim
Tükenme_Günü = D0 + Stok_Günü
Durmuş_Gün = (Tükenme_Günü - Kullanılabilir_Tarih) if >0 else 0
```

**Output Model**:
```python
class RiskAssessment(BaseModel):
    signal_id: str
    probability_score: float  # 0-5
    impact_score: int  # 1-5
    risk_score: float  # 0-25
    risk_category: str  # "Low", "Medium", "High"
    available_date: date  # ETA + customs + internal + QA
    stock_coverage_days: float
    depletion_date: date
    downtime_days: float
    downtime_cost: float
    at_risk_orders: List[str]
    total_inaction_cost: float
    justification: str  # Generated by LLM
```

---

### 2.3 Options Agent (Rule-based + LLM Suggestion)

**Input**:
- Risk assessment from Agent 2
- Stok_Durumu, Tedarik_Kaynaklari, Rota_Secenekleri, Malzemeler, Sevkiyatlar sheets

**Processing**:
1. Generate transfer options (inter-warehouse)
2. Generate alternative supplier options
3. Generate route change options
4. Generate expedited shipping options
5. Apply qualification constraints (pharma = registered only)
6. Generate hybrid combinations

**Constraints**:
- Pharma: Only "Ruhsatta Kayıtlı" suppliers
- MOQ: Minimum order quantities
- Capacity: Supplier production capacity limits
- Qualification: Required for regulated materials

**Output Model**:
```python
class MitigationOption(BaseModel):
    option_id: str
    option_type: str  # "transfer", "alternative_supplier", "route_change", "expedited", "hybrid"
    details: str
    available_days_from_now: int
    cost: float
    co2_kg: float
    risk_score: float  # 0-5
    constraints_satisfied: List[str]
    constraints_violated: List[str]
    feasibility: str  # "Feasible", "Conditional", "NotFeasible"
    llm_suggestion: Optional[str] = None  # Justification text
```

---

### 2.4 Decision Agent (Deterministic + LLM Rationale)

**Input**:
- Mitigation options from Agent 3
- Parametreler sheet (weights, thresholds)

**Processing**:
1. Simulate daily inventory for each strategy
2. Calculate downtime days and total cost per strategy
3. Compute weighted CKKV score
4. Rank options
5. Select recommended strategy
6. Generate justification with LLM

**CKKV Formula**:
```
ÇKKV_Puanı = 0.45×P_Maliyet + 0.30×P_Durus + 0.10×P_CO2 + 0.15×P_Risk
```

**Output Model**:
```python
class DecisionResult(BaseModel):
    signal_id: str
    recommended_option: MitigationOption
    rank: int
    all_options_ranked: List[MitigationOption]
    simulation_summary: Dict[str, Any]
    ckkv_score: float
    justification: str  # Generated by LLM
    recommended: bool
```

---

### 2.5 Orchestration Agent (Deterministic)

**Input**: Signal selection (from UI), State directory

**Processing**:
1. Load input data
2. Execute Agent 1 → Signal extraction
3. If risk category is "Low": stop, return low-risk result
4. Execute Agent 2 → Risk assessment
5. Execute Agent 3 → Option generation
6. Execute Agent 4 → Decision
7. Save state to JSON
8. Return results to UI

**State Structure**:
```json
{
  "signal_id": "SG-2611-001",
  "analysis_date": "2026-11-25",
  "agent_1": {...},
  "agent_2": {...},
  "agent_3": {...},
  "agent_4": {...},
  "final_decision": {...},
  "status": "completed" | "low_risk" | "error"
}
```

**Error Handling**:
- Stop execution on error
- Log detailed error message
- Save partial state if possible

## 4. LLM Integration

### 4.1 Amazon Bedrock (Production)
```python
import boto3
from botocore.exceptions import ClientError

def call_claude(prompt: str, max_tokens: int = 2000) -> str:
    bedrock = boto3.client('bedrock-runtime', region_name='us-east-1')
    body = json.dumps({
        "prompt": f"\n\nHuman: {prompt}\n\nAssistant:",
        "max_tokens_to_sample": max_tokens,
        "temperature": 0.1,
        "top_p": 0.9
    })
    response = bedrock.invoke_model(body=body, modelId='anthropic.claude-v2')
    return json.loads(response['body'].read())['completion']
```
